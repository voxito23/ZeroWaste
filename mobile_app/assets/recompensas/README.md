# Fallbacks móviles de recompensas

Estas imágenes se empaquetan como respaldo visual. El catálogo, los costos, el stock y el estado siempre provienen de FastAPI.

- PNG o WebP.
- 800 × 800 px y relación 1:1.
- Menor a 500 KB.
- Fondo blanco o transparente.
- No cambies los nombres sin actualizar el mapeo de `RewardsStoreScreen`.
