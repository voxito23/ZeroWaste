# DNS inventory before delegation

| Tipo | Nombre | Valor | Prioridad | TTL | Proxy | Propósito | Verificado |
|---|---|---|---:|---:|---|---|---|
| | | | | | | | |

Inventory all root/www A, AAAA, CNAME, subdomains and validations; MX, SPF, DKIM, DMARC, mail, webmail, autodiscover/autoconfig and provider TXT/CNAME; plus CAA, SRV, Google and external validations. Do not delete apparently unused records. Record previous nameservers and whether a DS exists. Values must come from Neubox/providers, never from examples.
