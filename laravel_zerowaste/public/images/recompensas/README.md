# Imágenes de recompensas

- Formato recomendado: PNG o WebP.
- Tamaño recomendado: 800 × 800 px, relación 1:1.
- Peso recomendado: menor a 500 KB.
- Fondo blanco o transparente.
- Conserva exactamente los nombres definidos en el catálogo.

Las imágenes originales entregadas se copiaron sin alterarlas. Antes de producción conviene optimizar `termo_reutilizable.png` y `bolsa_reutilizable.png`, y recortar a 1:1 `compostera_domestica.png`, `kit_botes_separacion.png` y `kit_cubiertos_reutilizables.png`.
